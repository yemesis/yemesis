## Featured Projects

### 🧬 Precision Nutrient Delivery for Tissue Engineering Bioreactors
Designed and conducted 80+ experiments to evaluate and optimise an in-line flow sensor within a perfusion bioreactor for bone tissue engineering, improving real-time flow measurement accuracy by approximately 20%.

### 🫀 Medical Imaging & Analysis
Performed manual segmentation of cardiac MRI datasets using 3D Slicer and evaluated the segmentation against gold-standard data using quantitative performance measures.

### 🦴 Spinal Implant Design
Contributed to the development of a novel balloon kyphoplasty device for metastatic spinal cord compression and evaluated the design using Finite Element Analysis.

### 📊 Python Data Analysis & Machine Learning
Used Python for exploratory data analysis, regression modelling and model evaluation, comparing linear regression with gradient boosting.

### 🧫 Tissue Engineering & Regenerative Medicine
Investigated the effect of agarose concentration on the mechanical properties and glycosaminoglycan production of chondrocyte-seeded tissue-engineering constructs.

### 📈 EMG Signal Analysis
Processed and analysed surface EMG signals using MATLAB, including filtering, rectification, RMS analysis and Fast Fourier Transform analysis.
